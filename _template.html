    softmax з температурою
    import numpy as np

def softmax(z, T=1.0):
    z = np.asarray(z) / T
    e = np.exp(z - z.max())  # стабільність
    return e / e.sum()

print(softmax([2.0, 1.0, 0.1], T=0.5))

    Перевірте себе

    Що станеться з розподілом softmax, якщо температура T → 0?
    Ділення на малу T розтягує різниці між логітами, тож softmax наближається до argmax.
