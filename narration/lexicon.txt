# Як TTS має вимовляти слова: «написання = вимова». Впливає лише на звук, субтитри показують написання.
# «+» після голосної — наголос. Регістр написання не важливий. Довші записи застосовуються першими.
# Латиницю StyleTTS2 не читає, тому кожне англійське слово з озвучки має бути тут.

Attention Is All You Need = ете+ншн із о+л ю ні+д
Google = гу+гл
RNN = ер-ен-е+н
query = кві+рі
key = кі+
value = ве+лью
Python = па+йтон
KeyError = кі+-е+рор
softmax = софтма+кс
